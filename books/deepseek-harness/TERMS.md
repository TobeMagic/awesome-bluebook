# 术语表与动词表

两份都必须在动笔前定。规范见 `../../CONVENTIONS.md §6` 与 `../../STYLE.md §二.2.11`。

---

## 一、动词表（一动作一动词）

**同一动作全书只用同一个动词。** 这是 ASD-STE100 里最值钱的一条规则。
同义轮换会让读者以为这是两件事，而这种错读者自己发现不了。

| 统一用 | 禁止轮换 | 为什么选它 |
|---|---|---|
| **检查** | 校验、核查、确认、验证 | 「检查」最直白；「验证」在中文语境里常被误解为「跑测试」 |
| **装**（装插件、装配） | 安装、装载、载入 | 官方语境的 install 就译「装」，短且无歧义 |
| **加载** | 装载、载入、读入 | 只用于「系统按顺序把包立起来」这一个动作 |
| **替换** | 替代、取代、置换 | 「替换」暗示「换掉原来的」，是本项目的核心动作 |
| **依赖** | 依靠、仰赖、依托 | 与 `dependencies` 字段直接对应 |
| **配置** | 设置、设定、配制 | 与 `settings` / `config` 两个词根的统一译法 |
| **启动** | 开启、起动、运行 | 「启动」是一次性的；「运行」是持续态，两者不同，不要混用 |
| **注册** | 登记、挂载、注入 | 与 Cordis 的 register 语义一致 |
| **执行** | 运行、调用、跑 | 用于工具调用真正发生的那一步 |
| **派**（派活、派小弟） | 分发、分配、委派 | 只用于 subagent 场景，是本书的口语表达 |

**新增动作时**：先在这张表里挑一个已有的词。挑不到再新增，并补一行禁用词。

## 二、包名与 ctx 键（必须逐字一致）

不得简写、不得意译、不得加中文后缀。写 `` `ctx.tools` ``，不写「工具服务」。

| 包 | 职责 | ctx 键 |
|---|---|---|
| `core/session` | 仅追加的 `SessionEvent` 日志与内存存储 | `ctx.sessions` |
| `core/system-prompt` | 提示词片段与工具 schema 的组装 | `ctx.systemPrompt` |
| `core/tools` | 作用域化的工具注册表 + 带把关的执行流水线 | `ctx.tools` |
| `core/agent` | `Agent` 接口、活跃 agent 注册表、`agent/*` 事件 | `ctx.agents` |
| `core/agent-loop` | 实现该接口的默认驱动器 | `ctx.agentLoop` |
| `core/scope` | 按 agent 划分作用域的注册原语 | 库，无 ctx 键 |
| `llm/llm` | 消息与流式词汇表 + 适配器 seam | `ctx.llm` |
| `webhook/webhook` | 已认证 delivery 分派、Workspace Session 创建 | `ctx.webhookRuntime` |

**事件名**：写 `` `agent/*` ``、`` `tools/pre-execute` ``、`` `session/*` `` 这种原文形式，
不写「执行前钩子」这类意译。

## 三、易混术语（本书统一说法）

| 别写成 | 写成 | 说明 |
|---|---|---|
| Harness、框架、系统（混用） | **Harness**（本书）、框架（他处系统语境） | 指本仓库时一律 Harness |
| 包、模块、组件（混用） | **包** | 与 `package.json` 一一对应。模块/组件不出现 |
| 分组 | **分组** | `packages/<group>/` 这一层，55 个 |
| 插件 | **插件** | 与「包」的区别：包是文件实体，插件是它在运行时的角色 |
| 内核、核心（混用） | **内核层** / **内核四件套** | 层是分层概念，四件套指 session/llm/agent/tools |
| 沙箱、沙盒（混用） | **沙箱** | 统一，与 `sandbox` 分组对应 |
| 会话、session（中英混用） | **会话**（叙述）、`SessionEvent`（专名） | 专名保持英文 |

## 四、数字口径（写数字时必须能答）

任何统计数字都要能回答三个问题：

1. **统计了什么** —— 例如「`packages/` 下所有 `package.json`，按包名去重」
2. **排除了什么** —— 例如「不含 `node_modules/` 与 `dist/`」
3. **哪个 commit** —— 例如 `639ed015397290b3745d163aafe02ffee4aa3f84`

答不出来的数字不写进书里。
